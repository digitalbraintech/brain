# Bundled service icons

Icons identify the connected specialist. The UI loads only the local assets in
`neuron_icon.dart`; descriptor values cannot load remote images or arbitrary paths.

## Gmail

`gmail.svg` is the unchanged Gmail SVG referenced by the official Google Workspace
Gmail product page, downloaded on 2026-09-05:
https://www.gstatic.com/images/branding/productlogos/gmail_2026/v2/web/192px.svg

Source page: https://workspace.google.com/products/gmail/.
Gmail and its logo are trademarks of Google LLC.

## Salesforce

`salesforce.svg` reuses the unchanged asset already bundled in the shell. The
original was retrieved on 2026-08-31 from Salesforce's official static asset host:
https://c1.sfdcstatic.com/content/dam/sfdc-docs/www/logos/logo-salesforce.svg

Salesforce and its logo are trademarks of Salesforce, Inc.

## Aspire

`aspire-icon-32.svg` is the unchanged official Aspire icon downloaded from
https://microsoft.github.io/aspire-brand/logo/aspire-icon-32.svg on 2026-09-05.

The artwork is provided under CC0 1.0. Microsoft retains trademark rights in the
Aspire name and logo. Guidance: https://microsoft.github.io/aspire-brand/.

Keep the mark unchanged; apply activity motion to its surrounding UI.
